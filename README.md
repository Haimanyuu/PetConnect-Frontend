# PetConnect-Frontend
PetConnect is a user-friendly front-end web application built with React and TypeScript, designed to connect pet


Steps to clone 

Clone the Project: git clone [https://github.com/SBNA-Game-Show/Geo-Guesser.git](https://github.com/Haimanyuu/PetConnect-Frontend.git) 
cd your-project-name Or go to vs code and cmd+Shift +P opens the palette click git clone

Install Dependencies: in folder /Petconnect-frontend
npm create vite@latest petconnect-frontend

Select: React → JavaScript

Move into the folder:

cd petconnect-frontend
npm install
npm run dev
